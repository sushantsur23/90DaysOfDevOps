# Linux Commands Cheat Sheet

## 1. Process Management

| Command | Usage |
|---|---|
| ps aux | List running processes with CPU and memory usage. |
| ps -ef | Show processes with full details, including parent PID. |
| top | Monitor processes and system resource usage in real time. |
| htop | Interactive process viewer with easier navigation than top (if installed). |
| pgrep <name> | Find process IDs by process name. |
| kill <PID> | Send a termination signal to a specific process. |
| kill -9 <PID> | Forcefully terminate a process when normal termination fails. |
| systemctl status <service> | Check the current status of a systemd service. |
| journalctl -u <service> | View logs generated by a systemd service. |

## 2. File System & Storage

| Command | Usage |
|---|---|
| pwd | Display the current working directory. |
| ls -lah | List files, including hidden files, with readable sizes and details. |
| cd <directory> | Change to another directory. |
| find /path -name "<pattern>" | Search for files or directories by name. |
| du -sh <directory> | Show the total disk space used by a directory. |
| df -h | Check filesystem capacity and available disk space. |
| free -h | Display RAM and swap usage in human-readable form. |
| chmod <mode> <file> | Change file or directory permissions. |
| chown <user>:<group> <file> | Change file ownership and group. |

## 3. Networking Troubleshooting

| Command | Usage |
|---|---|
| ping <host> | Test basic network reachability and latency. |
| ip addr | Display network interfaces and assigned IP addresses. |
| ip route | Display the system's routing table. |
| dig <domain> | Query DNS records and troubleshoot name resolution. |
| curl -I <url> | Check HTTP response headers and basic web connectivity. |
| traceroute <host> | Trace the network path toward a destination (if installed). |


For Process issue: check in the direction of ps → top → systemctl → journalctl

For Disk issue: check in the direction of df -h → du -sh

For Network issue:check in the direction of ip addr → ip route → ping → dig → curl → ss
